# Changelog

All notable changes to ReelFlow will be documented here.

## [Unreleased]

- Preparing for the first public release.
- Finalizing custom branding and extension icons.
- Completing privacy and security reviews.
- Preparing Mozilla Add-ons submission.

## [0.4.0]

- Improved communication between isolated and page-level scripts.
- Added bounded initialization retries.
- Introduced settings acknowledgements.
- Added engine status diagnostics.
- Improved visibility property restoration.
- Added error reporting.

## [0.3.0]

- Redesigned the extension popup.
- Introduced a minimal dark-purple interface.
- Added an expandable About section.
- Improved keyboard accessibility.
- Added reduced-motion support.
- Improved settings error handling.

## [0.2.0]

- Introduced background playback controls.
- Added persistent playback preferences.
- Added support for simultaneous playback across Instagram tabs.

## [0.1.0]

- Initial background playback proof of concept.
